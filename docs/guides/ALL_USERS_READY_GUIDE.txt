## 🧪 TESTING WORKFLOW #1: Complete Task Cycle

**Duration**: 15 minutes  
**Roles Needed**: 1 Manager, 1 Worker  
**Example**: Jane (Manager) & John (Worker)

### Step 1: Manager Creates Task (Jane)
```
1. Login as: jane.smith@worktrack.com / Manager123!
2. Go to: Tasks → Create Task
3. Fill:
   - Title: "Q1 Sales Report"
   - Description: "Compile quarterly sales data"
   - Deadline: 2026-03-31
   - Priority: High
   - Assign to: John Doe, Emma Wilson
4. Click: Create Task
```

### Step 2: Worker Views Task (John)
```
1. Logout (jane.smith@worktrack.com)
2. Login as: john.doe@worktrack.com / Worker123!
3. Go to: Dashboard
4. See: "Q1 Sales Report" in assigned tasks
5. Click: View task details
```

### Step 3: Worker Creates Submission (John)
```
1. On task detail page
2. Click: "Create Submission"
3. System creates draft automatically
4. Click: "Edit" (to add content)
5. Upload: Test file (.pdf, .xlsx, .doc)
6. Add: Notes/explanation
7. Click: "Save"
```

### Step 4: Worker Submits (John)
```
1. Review submission content
2. Click: "Submit" button
3. Confirm: "Ready to submit?"
4. Status: Changes to "Submitted"
```

### Step 5: Manager Reviews (Jane)
```
1. Logout (john.doe@worktrack.com)
```

## 🆘 TROUBLESHOOTING

### Issue: Can't Login
**Solution**: 
- Verify email is exact (case-insensitive, but full email required)
- Check password is exact (case-sensitive!)
- Ensure user is active
- Check database connection

### Issue: Can't See Assigned Tasks
**Solution**:
- Verify you're logged in as the assigned worker
- Manager created task with your email address
- Task status is "pending" or "in_progress"
- Not already submitted by you

### Issue: Submit Button Disabled
**Solution**:
- Submission must be in "Draft" status
- File must be uploaded
- Must have text/notes added
- Task must be assigned to you

### Issue: Can't Review Submission
**Solution**:
- Must be logged in as manager
- Submission must be in "Submitted" status
- Task must belong to your department
- You must have manager role
