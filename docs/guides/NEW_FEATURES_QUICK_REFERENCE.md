## 📍 QUICK FIND GUIDE

### For WORKERS

#### 1️⃣ Create Submission Button
**Location**: Task Detail Page → Right Sidebar  
**How to Find**: 
1. Click on any task from your dashboard
2. Look at the RIGHT SIDE of the screen
3. Find the **GREEN PANEL** with "Create Submission"
4. Click the green **"Create New Submission"** button

**What it does**: Creates a new submission for that task

---

#### 2️⃣ File Upload
**Location**: Submission Form Page  
**How to Find**:
1. After clicking "Create New Submission"
2. You'll see a form
3. Scroll down to find the **"Upload File"** section
4. Click to choose and upload your file

**What it does**: Uploads your work file for review

---

#### 3️⃣ Submit for Review Button
**Location**: Submission Detail Page → Draft Actions Section  
**How to Find**:
1. After creating submission, you'll be on the submission detail page
2. If status is "Draft" (blue badge), scroll down
3. Find the **BLUE SECTION** labeled "Draft Actions"
4. Click **"Submit for Review"** button

**What it does**: Sends your submission to manager for review

---

#### 4️⃣ Submission Status Timeline
**Location**: Submission Detail Page → Right Sidebar  
**How to Find**:
1. On any submission detail page
2. Look at the RIGHT SIDE of the screen
3. Find the section with **TIMELINE MARKERS**
4. Shows: Created → Submitted → Reviewed status

**What it does**: Shows progress of your submission

---

#### 5️⃣ Download Your File
**Location**: Submission Detail Page → File Section  
**How to Find**:
1. On submission detail page, scroll to "Submission File"
2. Find the **BLUE DOWNLOAD BUTTON**
3. Click it to download your uploaded file

**What it does**: Downloads the file you uploaded

---

### For MANAGERS

#### 1️⃣ Pending Submissions Panel
**Location**: Manager Dashboard → Main Content Area  
**How to Find**:
1. Click "Dashboard" from navbar
2. Look for **YELLOW CARD** labeled "Pending Submissions for Review"
3. Shows list of submissions waiting for review

**What it does**: Shows all submissions waiting for your review

---

#### 2️⃣ Review Button
**Location**: Pending Submissions Panel or Submissions List  
**How to Find**:
1. In the Pending Submissions Panel on dashboard
2. Each submission has a **BLUE "Review" BUTTON** on the right
3. Click it to open the submission

**What it does**: Opens the submission detail page for review

---

#### 3️⃣ Download Submission File
**Location**: Submission Detail Page → File Section  
**How to Find**:
1. On submission detail page, scroll to "Submission File"
2. Find the **BLUE DOWNLOAD BUTTON**
3. Click to download worker's file

**What it does**: Downloads the file submitted by worker

---

#### 4️⃣ Add Feedback & Score
**Location**: Submission Detail Page → Manager Review Section  
**How to Find**:
1. Scroll down on submission detail page
2. Find **YELLOW SECTION** "Manager Review"
3. Enter feedback in text area
4. Enter score (0-100) in number field

**What it does**: Add your review comments and score

---

#### 5️⃣ Approve/Reject Buttons
**Location**: Submission Detail Page → Manager Review Section  
**How to Find**:
1. In the Manager Review section
2. Find two buttons at bottom: **"Approve"** (green) and **"Reject"** (red)
3. Click one to submit your decision

**What it does**: Approves or rejects the submission

---

### For ADMINS

#### 1️⃣ Workflow Visualization
**Location**: Admin Dashboard → Upper Content Area  
**How to Find**:
1. Click "Admin Dashboard" from navbar
2. Find **"Workflow & Submission Tracking"** section
3. Shows: Draft → Submitted → Under Review → Completed stages

**What it does**: Shows visual overview of all submissions

---

#### 2️⃣ Workflow Stages with Counts
**Location**: Workflow Visualization Section  
**How to Find**:
1. In the Workflow section
2. Five colored boxes showing:
   - 📝 Draft (blue) = number of drafts
   - 📤 Submitted (light blue) = number submitted
   - ⏳ Under Review (yellow) = number reviewing
   - ✅ Completed (green) = number approved

**What it does**: Shows status distribution of submissions

---

#### 3️⃣ File Tracking Dashboard
**Location**: Admin Dashboard → File Tracking Section  
**How to Find**:
1. Scroll down on Admin Dashboard
2. Find **"Submission Files Summary"** section
3. Shows 4 cards with:
   - Total Files Uploaded
   - Average File Size
   - Total Submissions
   - Completion Rate %

**What it does**: Shows file upload statistics

---

#### 4️⃣ Download Recent Submission Files
**Location**: Admin Dashboard → Recent Submission Files Panel  
**How to Find**:
1. Below File Tracking section
2. Find **LEFT CARD** labeled "Recent Submission Files"
3. Each file has a **DOWNLOAD BUTTON**
4. Click to download

**What it does**: Download any recent submission file

---

#### 5️⃣ Management Tools
**Location**: Admin Dashboard → Management Tools Panel  
**How to Find**:
1. On Admin Dashboard, find **"Management Tools"** card
2. Four buttons:
   - **Manage Users**
   - **Manage Tasks**
   - **Manage Departments**
   - **System Settings**

**What it does**: Access admin management features

## 🔍 TROUBLESHOOTING

### Can't Find Create Submission Button?
1. ✅ Are you on a task detail page?
2. ✅ Are you a worker?
3. ✅ Check right sidebar (may need to scroll right on mobile)
4. ✅ Refresh the page if not visible

### Can't See Manager Review Section?
1. ✅ Is submission status "Submitted" or "Under Review"?
2. ✅ Are you logged in as manager/admin?
3. ✅ Check yellow section below task info

### Can't Download File?
1. ✅ Is there a file uploaded?
2. ✅ Check the "Submission File" section for download button
3. ✅ Try right-click → "Save As..."

### Can't Find Pending Submissions Panel?
1. ✅ Are you a manager?
2. ✅ Open Dashboard (home icon)
3. ✅ Look for yellow card with "Pending Submissions"
4. ✅ May be below the task list

## 🔄 COMMON WORKFLOWS

### Worker Submits Work
```
1. Dashboard → Click Task
2. Click "Create New Submission" (green button)
3. Upload file
4. Add notes
5. Click "Submit for Review" (blue button)
6. Wait for manager review
7. Check timeline for status
```

### Manager Reviews Work
```
1. Dashboard → See "Pending Submissions" (yellow panel)
2. Click "Review" button
3. Download file to check
4. Add feedback in text area
5. Enter score (0-100)
6. Click "Approve" or "Reject"
7. Worker gets notified
```

### Admin Tracks Workflow
```
1. Dashboard → Open Admin Dashboard
2. See Workflow Visualization
3. Click on workflow stages to see counts
4. Download files from Recent Files section
5. View statistics in File Tracking
6. Access management tools
```
